# 마린글래스 (MarinGlass) - 맞춤 유리 실시간 사진 자동 견적 및 공장 직영 플랫폼

우리집 식탁·책상·테이블 맞춤 유리, 실물 인테리어 사진과 동전 실측 가이드로 1초 만에 견적 확인!

## ✨ 주요 기능
1. **사진 보고 고르는 비주얼 견적기 (Visual Estimator)**: 8종 유리 실물 사진 카드 & 룸 뷰 렌더링
2. **10초 스마트 맞춤 추천 위저드 (Smart Recommender)**: 3가지 질문으로 최적 유리/두께/강화/R값 1초 자동 세팅
3. **지능형 형태(Shape) 분기**: 원형/타원형 선택 시 모서리 R 자동 0원 처리 & 직사각형 선택 시 동전 R값(100원/500원) 연동
4. **완전한 동적 CRUD 관리자 마스터 (Admin Dashboard)**: 유리 품종 추가, 수정, 삭제, 품절 토글 및 단가/배송비 실시간 제어
5. **100% 안심 파손 보상 시스템**: 배송 중 파손 시 당일 무상 재제작 보증
